# מערכת ניהול ועד בית 🏢

מערכת ווב מלאה בעברית (RTL) לניהול ועד בית / חברת ניהול בניינים: ניהול בניינים, דיירים, דרישות תשלום, גבייה, קריאות תיקון, ספקים, הוצאות ודוחות.

## טכנולוגיות

- **Next.js 14** (App Router) + TypeScript
- **Prisma ORM** + SQLite (פיתוח) — מוכן למעבר ל-Postgres
- **Tailwind CSS** + רכיבי UI בסגנון shadcn
- אימות JWT (jose) עם עוגיית HttpOnly והרשאות מבוססות תפקידים

## התקנה והרצה

```bash
cd building-management
npm install
cp .env.example .env      # ערכו את AUTH_SECRET בפרודקשן
npx prisma migrate dev    # יוצר את מסד הנתונים ומריץ seed
npm run dev               # http://localhost:3000
```

## תפקידים והרשאות

- **מנהל (ADMIN)** — רואה ומנהל את כל הבניינים, הדיירים והכספים.
- **ועד בית (COMMITTEE)** — מנהל את הבניין שלו בלבד: דיירים, דרישות, גבייה, תיקונים.
- **דייר (RESIDENT)** — רואה את הדרישות והתשלומים שלו ופותח קריאות תיקון.

## מודולים

1. **לוח בקרה** — KPIs: סה"כ נגבה, חוב פתוח, יתרת קופה, אחוז גבייה, קריאות פתוחות, חייבים מובילים.
2. **בניינים** — ניהול בניינים ודמי ועד חודשיים לדירה.
3. **דיירים** — דיירים משויכים לדירות, בעלים/שוכר, יתרת חוב לכל דייר.
4. **דרישות תשלום** — דרישה בודדת (דמי ועד / מיוחד / קנס) + **מחולל דרישות חודשי** לכל דיירי בניין (idempotent — מדלג על מי שכבר חויב). דרישות שעבר מועדן מסומנות "בפיגור".
5. **תשלומים וגבייה** — רישום תשלום (מזומן/העברה/צ'ק/מקוון), שיוך לדרישה עם מילוי אוטומטי של הסכום הנותר, תמיכה בתשלום חלקי.
6. **תיקונים ותחזוקה** — פתיחת קריאה (גם ע"י דייר) עם מיקום בבניין, קטגוריה, עדיפות, שיוך ספק, עלות. סגירת קריאה עם עלות וספק רושמת הוצאה אוטומטית.
7. **תחזוקה מונעת** — תוכניות תחזוקה מחזוריות (בדיקת מעלית, ניקוי מאגר מים...) שמייצרות קריאות תיקון אוטומטית כשמגיע המועד, עם קידום מועד לפי תדירות.
8. **תזכורות חוב במייל** — שליחת תזכורת מפורטת (פירוט דרישות + סה"כ) לדייר בודד או לכל החייבים בלחיצה. עובד עם SMTP אמיתי (משתני `SMTP_*`) או במצב סימולציה עם יומן הודעות.
9. **ספקים וחוזי שירות** — פנקס ספקים + חוזים עם עלות חודשית ותוקף, כולל התראת "פוקע בקרוב" בלוח הבקרה ובמסך הספקים.
10. **הודעות לדיירים** — לוח מודעות לכל בניין עם נעיצה; ההודעות האחרונות מוצגות לדייר בלוח הבקרה שלו.
11. **הוצאות** — רישום הוצאות בניין לפי קטגוריה וספק.
12. **דוחות וייצוא** — סיכום פיננסי פר בניין, גבייה חודשית, הוצאות לפי קטגוריה, דוח חייבים; ייצוא CSV (חייבים/תשלומים/הוצאות) שנפתח תקין באקסל בעברית.
13. **קבלות אוטומטיות** — תשלום ללא אסמכתא מקבל מספר קבלה רץ (KBL-שנה-מספר).
